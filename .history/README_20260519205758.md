# Qlaudy Museum

## Project Description
Qlaudy Museum is a responsive landing page for a modern museum. The project focuses on clean layout, semantic HTML, responsive design, animations, and performance optimization. It is built as a learning project to practice frontend development and UI implementation from a design.

## Getting Started

### Clone the repository:
```bash
git clone https://github.com/qlaudy/qlaudy-museum.git
cd qlaudy-museum

### Install dependencies:
```bash
npm install
```

### Run the project locally:
```bash
npm start
```
